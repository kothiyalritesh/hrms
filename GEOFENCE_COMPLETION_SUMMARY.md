Employee initiates check-in\n2. GPS location captured\n3. Distance calculated to nearest office\n4. Violation type determined:\n   - ≤200m → Safe (no violation)\n   - 200-400m → Warning (soft warning)\n   - >400m → Violation (blocked)\n5. Compliance status updated\n6. Performance score adjusted if non-compliant\n```\n\n### Compliance Scoring\n```\nBase Score: 100\nPer Violation: -10 points\nNon-Compliant Status: -20 points additional\n\nExample:\n- 0 violations → 100 (Compliant)\n- 1 violation → 90 (Warning)\n- 2 violations → 80 (Warning)\n- 3+ violations → <70 (Non-Compliant)\n```\n\n### Performance Impact\n```\nFinal Score = Base Score - Compliance Penalty\n\nExample:\n- Base: 85\n- Compliance: Non-Compliant\n- Penalty: -20\n- Final: 65 ⬇️\n```\n\n---\n\n## 📁 Files Created\n\n### Services\n✅ `services/geofence-violation.service.ts`\n   -
