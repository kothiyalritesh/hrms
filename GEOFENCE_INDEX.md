violation\n- **Warning Zone** (200-400m): Soft warning, check-in allowed\n- **Violation Zone** (>400m): Hard violation, check-in blocked\n\n### Compliance Scoring ✅\n- Score range: 0-100\n- Base: 100 points\n- Penalty: -10 per violation\n- Status: Compliant/Warning/Non-Compliant\n\n### Automatic Performance Impact ✅\n- Non-compliant status: -20 points on performance score\n- Integrated with performance metrics\n- Monthly calculation with compliance penalty\n\n### Manager Notifications ✅\n- Warning zone: ⚠️ Alert\n- Violation zone: 🚨 Alert\n- Automatic notification to reporting manager\n- Metadata included (distance, office, type)\n\n### Admin Dashboard ✅\n- Real-time compliance analytics\n- Compliance rate percentage\n- Average compliance score\n- Weekly/monthly violations\n- Non-compliant employees list\n- Filter by status\n- Employee violation details\n\n### Database Tracking ✅\n- Violation event logging\n- Compliance status tracking\n- Audit trail for all violations\n- Performance metrics integration\n- RLS policies for security\n\n---\n\n## 🔄 Workflows\n\n### Employee Check-in Workflow\n```\nEmployee Initiates Check-in\n    ↓\nGPS Location Captured\n    ↓\nCalculate Distance to Office\n    ↓\nDetermine Violation Type\n├─ Safe (≤200m) → Allow check-in\n├─ Warning (200-400m) → Record + Notify + Allow\n└─ Violation (>400m) → Record + Notify + Block\n    ↓\nUpdate Compliance Status\n    ↓\nImpact Performance Score (if non-compliant)\n```\n\n### Compliance Status Progression\n```\nWeek 1: 1st Violation → Warning (Score: 90)\nWeek 1: 2nd Violation → Warning (Score: 80)\nWeek 1: 3rd Violation → Non-Compliant (Score: 70)\n        Performance Penalty: -20 points\n\nWeek 2: Violations continue → Non-Compliant (Score: 60)\n\nWeek 3: No violations → Status resets to Compliant\n        Performance Penalty: 0 points\n```\n\n---\n\n## 📊 Configuration\n\n```typescript\nGEOFENCE_CONFIG = {\n  SAFE_RADIUS: 200,                    // meters\n  WARNING_RADIUS: 400,                 // meters\n  VIOLATION_RADIUS: 400,               // meters\n  VIOLATION_THRESHOLD_WEEKLY: 3,       // violations to mark non-compliant\n  COMPLIANCE_PENALTY: 10,              // points per violation\n  NON_COMPLIANT_PENALTY: 20,           // additional penalty for status\n}\n```\n\n---\n\n## 🧪 Testing Checklist\n\n- [ ] Safe zone check-in (150m) - Allowed, no
