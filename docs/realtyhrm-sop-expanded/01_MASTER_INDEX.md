## Status rule

Material workflows and control rows are classified as VERIFIED, PARTIALLY IMPLEMENTED, DEFECTIVE, UNVERIFIED or NOT IMPLEMENTED in the coverage, traceability, test and defect registers. Individual step sections inherit the classification of their linked control row. A source path is not evidence that the deployed database, provider or device behavior is available.
