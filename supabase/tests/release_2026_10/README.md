# Release 2026-10 scenario tests (local only)

Self-checking SQL tests for the migrations in this release. Each scenario builds a fresh database from `mock_schema.sql`, applies the real migration twice (to prove idempotency), and stops with `FAIL …` at the first wrong result. This includes negative cases: self-approval, out-of-scope users, missing permission, and edits or deletes of audit history.

`mock_schema.sql` is generated by `build_mock_schema.py`. Tables are minimal stand-ins; the functions the migrations patch or call are copied verbatim from the migration files.

    $env:PGPASSWORD = "<local password>"
    powershell -ExecutionPolicy Bypass -File supabase/tests/release_2026_10/run.ps1 -Port 5432

Run only against a **local or disposable** PostgreSQL 15+. Never against the production project.
