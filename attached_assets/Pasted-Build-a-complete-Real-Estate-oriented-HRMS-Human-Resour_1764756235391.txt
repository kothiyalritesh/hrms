Build a complete Real Estate–oriented HRMS (Human Resource Management System) mobile application.
The tech stack must be:

React Native + Expo for iOS + Android

Backend: Firebase (Authentication, Firestore, Firebase Storage, Cloud Functions)

Also allow support for local offline storage using SQLite / AsyncStorage

The app must run smoothly, be responsive, secure, and scalable.

🎯 Overall Purpose of the App

The HRMS app should streamline employee management specifically for Real Estate companies, including:

Attendance & field tracking for site visits

Leave management

Payroll & salary slip generation

Task & workflow assignment

Document management (property files, HR docs)

Employee profiles & KYC

Real estate team structure & reporting hierarchy

Notifications

Dashboard & analytics for HR/admin

👤 User Roles

Employee (Sales, Marketing, Site Supervisor, Telecaller, Field Team)

HR

Team Lead / Manager

Admin / Super Admin

Each role should see different screens & access levels.
